## 1.0.0 (2026-09-07)

### ⚠ BREAKING CHANGES

* The build system is Vite rather than Babel and browserify.
`npm start` now serves the game itself instead of writing
`public/bundle.min.js`, `npm run build` emits a hashed bundle to `dist`, and
Node 26 or newer is required.
